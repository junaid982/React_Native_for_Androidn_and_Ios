                           THEORETICAL BACKGROUND
================================================================================

WHAT IS A SPLASH SCREEN?
-------------------------
A splash screen is the first screen that appears when a user launches a mobile
app. It typically shows the app logo or branding while the app loads in the
background. It makes the startup feel smooth and professional.


WHY MULTIPLE IMAGE SIZES?
--------------------------
Android devices have different screen densities (DPI = dots per inch).
To make the splash screen look sharp on every device, Android needs images
in multiple resolutions stored in separate drawable folders.


ANDROID SCREEN DENSITY TABLE
------------------------------
  Density Level     | Multiplier | Target Devices
  ------------------|------------|--------------------------------
  mdpi  (Medium)    | 1.0x       | Low-end / older devices
  hdpi  (High)      | 1.5x       | Mid-range phones
  xhdpi (X-High)    | 2.0x       | Most modern mid-range phones
  xxhdpi (XX-High)  | 3.0x       | High-end and flagship devices
  xxxhdpi (XXX)     | 4.0x       | Very high-resolution screens


REQUIRED SPLASH SCREEN IMAGE SIZES GENERATED BY APE TOOLS
-----------------------------------------------------------
  Folder Name         | Image Size (px)  | Density
  --------------------|------------------|--------
  drawable-land-hdpi  | 800  x  480      | 1.5x
  drawable-land-xhdpi | 1280 x  720      | 2.0x
  drawable-land-xxhdpi| 1920 x  1080     | 3.0x
  drawable-port-hdpi  | 480  x  800      | 1.5x
  drawable-port-xhdpi | 720  x  1280     | 2.0x
  drawable-port-xxhdpi| 1080 x  1920     | 3.0x


SOURCE IMAGE REQUIREMENT
--------------------------
  Size       : 4096 x 4096 px  (square)
  Format     : PNG
  Logo       : Centered in the canvas
  Background : Solid color or transparent


================================================================================
                              PRACTICAL STEPS
================================================================================


--------------------------------------------------------------------------------
STEP 1 — RESIZE YOUR IMAGE TO 4096 x 4096 px
--------------------------------------------------------------------------------

  Your source image must be exactly 4096 x 4096 px before uploading to APE Tools.
  If your image is a different size, resize it first.

  1.1  Open your browser and go to:
         https://image.pi7.org/resize-image-pixel

  1.2  Upload your logo or splash image on the website.

  1.3  Set the dimensions:
         Width  : 4096
         Height : 4096

  1.4  Click Resize and download the resized image.

  1.5  Save the downloaded PNG somewhere easy to find.
       Example:  Desktop\logo.png


--------------------------------------------------------------------------------
STEP 2 — GENERATE SPLASH SCREEN BUNDLE USING APE TOOLS
--------------------------------------------------------------------------------

  Website : https://apetools.webprofusion.com/#/tools/imagegorilla

  2.1  Open the website above in your browser.

  2.2  Under "Step 2 - Select Your Splashscreen", upload your 4096 x 4096 PNG.

  2.3  Check the "Android" checkbox to target Android platform.

  2.4  Under "Step 3 - Where the magic happens", click the "Kapow!" button.

  2.5  Download the ZIP file that is generated.

  2.6  Extract / unzip the downloaded ZIP file.

  2.7  Inside the extracted folder, navigate to:
         ApeToolsGeneratedAssets\bundle\android

  2.8  You will find these folders inside:

         drawable-land-hdpi\
             screen.png

         drawable-land-xhdpi\
             screen.png

         drawable-land-xxhdpi\
             screen.png

         drawable-port-hdpi\
             screen.png

         drawable-port-xhdpi\
             screen.png

         drawable-port-xxhdpi\
             screen.png

  NOTE: APE Tools names the image file "screen.png" by default.
        Remember this name — you will use it in launch_screen.xml in Step 5.


--------------------------------------------------------------------------------
STEP 3 — COPY SPLASH SCREEN BUNDLE INTO YOUR ANDROID PROJECT
--------------------------------------------------------------------------------

  3.1  Open your React Native project folder in File Explorer.

  3.2  Navigate to:
         android\app\src\main\res

  3.3  Copy all drawable folders from  ApeToolsGeneratedAssets\bundle\android
       and paste them into:
         android\app\src\main\res

  3.4  After copying, your res folder should look like this:

         res\
         ├── drawable\
         ├── drawable-land-hdpi\
         │     └── screen.png
         ├── drawable-land-xhdpi\
         │     └── screen.png
         ├── drawable-land-xxhdpi\
         │     └── screen.png
         ├── drawable-port-hdpi\
         │     └── screen.png
         ├── drawable-port-xhdpi\
         │     └── screen.png
         ├── drawable-port-xxhdpi\
         │     └── screen.png
         ├── mipmap-hdpi\
         ├── mipmap-xhdpi\
         ├── mipmap-xxhdpi\
         ├── mipmap-xxxhdpi\
         └── values\


--------------------------------------------------------------------------------
STEP 4 — INSTALL react-native-splash-screen
--------------------------------------------------------------------------------

  4.1  Open Command Prompt in your project root folder.

  4.2  Run this install command:

         npm i react-native-splash-screen --save

  4.3  Wait for installation to complete successfully.

  NOTE: React Native 0.60+ uses autolinking.
        You do NOT need to manually edit settings.gradle or build.gradle.
        The library links itself automatically.

  IMPORTANT — If your package.json also has react-native-bootsplash,
  remove it. Having both causes a "Duplicate class" build error:

         npm uninstall react-native-bootsplash


--------------------------------------------------------------------------------
STEP 5 — UPDATE MainActivity.kt
--------------------------------------------------------------------------------

  File location:
    android\app\src\main\java\com\<your-app-name>\MainActivity.kt

  5.1  Open MainActivity.kt in VS Code or any text editor.

  5.2  Delete everything inside the file.

  5.3  Paste this content.
       Replace "com.project" and "project" with your actual app package name:


package com.project

import com.facebook.react.ReactActivity
import com.facebook.react.ReactActivityDelegate
import com.facebook.react.defaults.DefaultNewArchitectureEntryPoint.fabricEnabled
import com.facebook.react.defaults.DefaultReactActivityDelegate
import android.os.Bundle
import org.devio.rn.splashscreen.SplashScreen

class MainActivity : ReactActivity() {

  override fun getMainComponentName(): String = "project"

  override fun onCreate(savedInstanceState: Bundle?) {
    SplashScreen.show(this)
    super.onCreate(savedInstanceState)
  }

  override fun createReactActivityDelegate(): ReactActivityDelegate =
      DefaultReactActivityDelegate(this, mainComponentName, fabricEnabled)
}


  5.4  Save the file.


  !! CRITICAL — THE BUG THAT CAUSES BUILD FAILURE !!
  ---------------------------------------------------
  The original document had a typo in the import line.
  This single typo causes two errors and the build fails completely.

  WRONG (from original doc) : import org.devio.rn.splashscreen.Splashscreen
                                                                ^^^^^^^^^^^
                                                                lowercase 's'

  RIGHT (use this)          : import org.devio.rn.splashscreen.SplashScreen
                                                                ^^^^^^^^^^^
                                                                capital 'S'

  The class name in the library is SplashScreen with a capital S.
  Writing Splashscreen (lowercase s) makes Kotlin unable to find the class,
  which then also makes SplashScreen.show(this) fail with "Unresolved reference".

  This one typo produces both errors you saw:
    Error 1 : Unresolved reference 'Splashscreen'   (wrong import)
    Error 2 : Unresolved reference 'SplashScreen'   (show() can't work)


  OTHER KOTLIN RULES TO REMEMBER
  --------------------------------
  Wrong : Import  (capital I)           Right : import  (lowercase i)
  Wrong : import ...SplashScreen;       Right : import ...SplashScreen  (no semicolons)
  Wrong : Missing import android.os.Bundle  causes "Unresolved reference: Bundle"
  Wrong : SplashScreen.show after super.onCreate
  Right : SplashScreen.show must always come BEFORE super.onCreate


--------------------------------------------------------------------------------
STEP 6 — CREATE layout FOLDER AND launch_screen.xml
--------------------------------------------------------------------------------

  The "layout" folder does NOT exist by default. Create it manually.

  6.1  Navigate to:
         android\app\src\main\res

  6.2  Create a new folder inside res named:
         layout

  6.3  Inside the layout folder, create a new file named:
         launch_screen.xml

  6.4  Open launch_screen.xml and paste this content:


<?xml version="1.0" encoding="utf-8"?>
<RelativeLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:orientation="vertical"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:background="#121928">

    <ImageView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:src="@drawable/screen"
        android:scaleType="centerCrop"
        android:layout_centerInParent="true" />

</RelativeLayout>


  6.5  Save the file.

  NOTE: android:src="@drawable/screen" refers to the screen.png files
        copied from APE Tools in Step 3.

        If APE Tools named your image differently (e.g. launch_screen.png),
        change  @drawable/screen  to  @drawable/launch_screen  to match.

        To confirm the image name: look inside any of the drawable folders
        you copied and use that exact filename (without the .png extension).


--------------------------------------------------------------------------------
STEP 7 — UPDATE styles.xml
--------------------------------------------------------------------------------

  File location:
    android\app\src\main\res\values\styles.xml

  7.1  Open styles.xml in a text editor.

  7.2  Delete everything inside the file.

  7.3  Paste this content:


<resources>

    <style name="AppTheme" parent="Theme.AppCompat.DayNight.NoActionBar">
        <item name="android:editTextBackground">@layout/launch_screen</item>
    </style>

</resources>


  7.4  Save the file.


--------------------------------------------------------------------------------
STEP 8 — UPDATE gradle.properties  (Fixes Duplicate Class build error)
--------------------------------------------------------------------------------

  File location:
    android\gradle.properties

  8.1  Open gradle.properties in a text editor.

  8.2  Check if these two lines already exist.
       If they are NOT present, add them at the bottom of the file:

         android.useAndroidX=true
         android.enableJetifier=true

  8.3  Save the file.

  WHY IS THIS NEEDED?
  react-native-splash-screen internally uses old "com.android.support" libraries.
  Jetifier converts them to modern "androidx" equivalents automatically.
  Without this you get:
  "Duplicate class android.support.v4... found in modules core and support-compat"


--------------------------------------------------------------------------------
STEP 9 — UPDATE App.tsx
--------------------------------------------------------------------------------

  File location:
    App.tsx  (project root folder)

  9.1  Open App.tsx in VS Code or any text editor.

  9.2  Delete the existing content and paste this:


import React, { useEffect } from "react";
import { Platform } from "react-native";
import SplashScreen from "react-native-splash-screen";

const App = () => {
  useEffect(() => {
    if (Platform.OS === "android") {
      SplashScreen.hide();
    }
  }, []);

  return (
    null
  );
};

export default App;


  9.3  Save the file.

  HOW IT WORKS:
  - SplashScreen.show(this) in Kotlin shows the splash when app launches.
  - SplashScreen.hide() in useEffect hides it once JS side has loaded.
  - Platform.OS === "android" ensures this only runs on Android.


--------------------------------------------------------------------------------
STEP 10 — CLEAN BUILD AND RUN THE APP
--------------------------------------------------------------------------------

  Run these commands ONE AT A TIME in Command Prompt.
  Start from your project root folder.

  10.1  Move into the android folder:

          cd android

  10.2  Clean the old build:

          gradlew clean

        Wait until you see:  BUILD SUCCESSFUL

  10.3  Go back to the project root:

          cd ..

  10.4  Run the app:

          npx react-native run-android

  10.5  Expected result:
        - App launches and shows your splash screen
        - After a moment it transitions into your main app screen
