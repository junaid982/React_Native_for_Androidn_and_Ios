Create Project in react native 


========================================================================================================================


1 - Create Project Folder 

# Create React Native APP

>>> npx @react-native-community/cli init project_name



>>> cd project_name
>>> code .





======================================================================================================================
# 2 - Install Required Libraries


# React Navigation Core
# Used for screen navigation and routing between pages/screens
>>> npm install @react-navigation/native


# Native dependencies required by React Navigation
# react-native-screens             -> Improves navigation performance using native navigation primitives
# react-native-safe-area-context   -> Handles safe area spacing for notches/status bars
# react-native-gesture-handler     -> Enables smooth gesture handling for navigation and swipes
# react-native-reanimated          -> Provides high-performance animations
# react-native-vector-icons        -> Adds customizable icon support
>>> npm install react-native-screens react-native-safe-area-context react-native-gesture-handler react-native-reanimated react-native-vector-icons


# Native Stack Navigator
# Used for stack-based navigation like Login -> Dashboard -> Profile
>>> npm install @react-navigation/native-stack


# Bottom Tab Navigator
# Used for bottom tab navigation like Home, Search, Profile tabs
>>> npm install @react-navigation/bottom-tabs


# Axios
# Used for making API requests (GET, POST, PUT, DELETE)
>>> npm install axios


# Async Storage
# Used for storing local data like JWT tokens, user settings, login session
>>> npm install @react-native-async-storage/async-storage


# Redux Toolkit + React Redux
# Used for global state management across the app
>>> npm install @reduxjs/toolkit react-redux


# Formik + Yup
# Formik -> Form handling and form state management
# Yup    -> Form validation and schema validation
>>> npm install formik yup


# React Native Image Picker
# Used for selecting images/videos from gallery or camera
>>> npm install react-native-image-picker


# React Native Permissions
# Used for requesting Android/iOS permissions like camera, storage, microphone
>>> npm install react-native-permissions


# React Native Vector Icons
# Used for app icons, tab icons, buttons, UI icons
>>> npm install react-native-vector-icons


# React Native Worklets
# Used for running animation/worklet logic on UI thread for better performance
>>> npm install react-native-worklets


# Specific Async Storage Version
# Used for compatibility with some React Native versions/projects
>>> npm install @react-native-async-storage/async-storage@1.23.1



========================================================================================================================


3 - Start Project 

>>> npx react-native run-android 


# 1st time it will take 5 to 10 min
