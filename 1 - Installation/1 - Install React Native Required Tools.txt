2 - JavaJDK

Version       : 17
Download Link : https://www.openlogic.com/openjdk-downloads


# JDK Configurations
---------------------------------------------------------------------------------------------------
a - JAVA_HOME ( System Variable / User Variable )


windows key > search "Enviroment variable" Open
CLick Enviroment variable


- User Variable 
New > 
variable name  : JAVA_HOME
variable value : C:\Program Files\OpenLogic\jdk-17.0.18.8-hotspot


- System Variable 
New > 
variable name  : JAVA_HOME
variable value : C:\Program Files\OpenLogic\jdk-17.0.18.8-hotspot 


---------------------------------------------------------------------------------------------------

b - Setup paths

- System Variable 
click paths > New 

C:\Program Files\OpenLogic\jdk-17.0.18.8-hotspot


New 

C:\Program Files\OpenLogic\jdk-17.0.18.8-hotspot\bin


Press OK to save 




# Verify Installation 

>>> java --version
>>> javac --version
